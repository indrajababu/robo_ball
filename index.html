Perception

See the ball in real time, every frame.

A high-frame-rate camera and a tight detection pipeline locate the ball with millisecond latency, so the robot has time to react before the ball lands.

Learn how perception works →
perception preview

Planning

Predict the trajectory, then move.

From a stream of ball positions we fit a projectile model, solve for the catch point, and generate a joint trajectory the robot can actually execute in time.

See the planning stack →
trajectory preview

Design

A CADed paddle, driven by a clean node graph.

We designed the end-effector in CAD to fit the arm's tool flange, then built the ROS nodes and controllers that turn camera frames into joint commands.
